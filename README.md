# DeltaOps Training

Landing page for DeltaOps Training: hands-on AI training for small businesses.

A single static page (`index.html`) with no build step. Open it in a browser, or view it on GitHub Pages.

- `logo-training.svg` / `logo-training-white.svg`: the DeltaOps Training lockup for light and dark backgrounds
- `logo.svg` / `logo-white.svg`: the original DeltaOps logo (`logo.svg` is also the favicon)
- `oliver.jpg`, `arpan.jpg`: team photos

Fonts load from Google Fonts. Every booking button links to the 30-minute HubSpot discovery call.
